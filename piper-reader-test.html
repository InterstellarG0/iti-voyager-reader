Voyager + Piper integration test

This is a separate test page. It does not modify the stable reader. It loads the LibriTTS-R model in your browser, extracts PDF text locally, and synthesizes audio on-device. The first model download is about 79 MB.

1. Load voice

Selected model: en_US-libritts_r-medium. Speaker label lilbritts_r maps to model speaker index 0 for source speaker ID 3922.

Ready. Click “Load Piper voice” to begin.

Model files are fetched from the upstream Piper voice repository and cached by your browser where supported. This test requires internet access for the initial download.

2. Use PDF text or paste text

PDF text extraction happens in this browser. Scanned pages require OCR, which this test does not include.

What this proves

  • Browser-side Piper synthesis using the selected multi-speaker model.
  • PDF text extraction feeding into Piper narration.
  • No paid API key or hosted speech-generation request.

This is an experimental page, not yet part of the stable reader. Browser compatibility, model licensing/redistribution, pause/resume, large-PDF chunking, and production error handling still need review before merging.
